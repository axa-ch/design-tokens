## CSS

```css
@import "./build/css/tokens.css";

.button {
  color: var(--axa-brand-blue);
}
```

## SCSS

```scss
@use "./build/scss/tokens.scss" as tokens;

.button {
  color: tokens.$axa-brand-blue;
}
```

## JavaScript

```js
import { brand, media } from "./build/js/tokens.js";

console.log(brand.blue);
console.log(media.up.md);
```

## Responsive tokens

CSS custom-media queries and SCSS/JavaScript media values use the same
`--axa-media-*` / `axa-media-*` names. The token model and available families
are described in the project README.
